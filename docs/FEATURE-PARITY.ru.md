# Сохранение возможностей UniDay 7.9.0

Исходный `UniDay_v7.9.0.js` прочитан целиком (3516 строк). В комплекте приложения сохранены **все 271 функции верхнего уровня**, включая вложенные функции, CSS/HTML и четыре независимых движка. `docs/legacy-manifest.json` фиксирует SHA-256 исходного файла и каждого последовательного сегмента функций. `scripts/extract-legacy.mjs` удаляет только завершающие вызовы запуска; он отказывается импортировать файл с непустыми личными настройками по умолчанию. Наличие кода и прохождение тестов не являются подтверждением установки на iPhone.

В приложение дополнительно входят native проверка версии и открытие AltStore, полная локальная резервная копия/восстановление, диагностика подписанного bundle/app-group, минимальный тест приложения и виджета. Эти части не заменяют старые возможности.

Локально выполнено `node --test tests/runtime.test.mjs`: 21 тест прошёл. Проверка SHA-256 охватывает все функции исходного файла. Тест смены версии создаёт новое окружение runtime из ранее сохранённых файлов и проверяет календарную ссылку, остановки, профиль, цепочки, заметки, правки, личные события, вещи и галочки. Дополнительно проверены неизменность пользовательского текста со словом Scriptable, ссылки холодного запуска и экспорт изменений даже при ошибке диска. Это моделирование данных; настоящее обновление через AltStore надо подтвердить отдельно на каждом телефоне.

Нужно честно подтвердить на iPhone: подпись двумя Apple Accounts и итоговые entitlements, доступ App Group и одинаковое значение app/widget, WidgetKit JSCore/Intl, работу нативных разрешений, фото/фонов/шрифтов, действия HTML-интерфейса и обновление IPA поверх текущей установки. Успех одного телефона не подтверждает второй.

Виджет получает сеть независимо от открытия app, когда iOS даёт Timeline запуск, используя те же движки и локальные кеши. iOS может отложить запуск и изменение заголовков/рейсов; системный таймер продолжает отсчёт. GPS-координаты текущего положения не записываются: сохранён только результат выбора зоны. WidgetKit host запрашивает геопозицию через публичный CoreLocation API только когда iOS разрешает обновления геопозиции виджету; при отказе/таймауте срабатывает исходный zone cache fallback с отметкой устаревания. Приложение запрашивает геопозицию при возврате в активное состояние и в исходных настройках/preview. Фактическое разрешение и обновление места ещё нужно подтвердить на обоих iPhone.

HTML-вывод для Shortcuts и внутренние флаги legacy сохранены как функции совместимости; запуск Scriptable не требуется. Native AppIntent экспортирует последний полный HTML для Shortcuts и открывает UniDay. В экспортируемом HTML используются исходные обработчики перехода к приложению, а данные соответствуют последнему сохранённому открытию UniDay. В самостоятельном app основные пользовательские действия доступны через свой интерфейс и `uniday://` ссылки. Приложение не управляет HTML-окном чужого приложения Shortcuts и не переносит разрешения или чужие уведомления из Scriptable автоматически.

runtime добавляет проверяемую регистрацию существующего `applyRefresh` closure в `presentInteractiveOverview` при загрузке в память. Файл исходника при этом не меняется, все его функции сохранены. Этот hook нужен, чтобы возврат в приложение обновлял также скрытые внутри исходного экрана серии календаря и очередь действий, а выбор другой недели не возвращал старый ICS. Обновление экрана использует исходную логику busy/signature, повторного чтения заметок/галочек, сохранения прокрутки и раскрытых карточек.
